# 채널 운영 지표 취합

## 상황

홍보팀 대내외 커뮤니케이션 채널 운영 담당자가 매달 온라인사보·유튜브·인스타그램·네이버 블로그 4개 채널의 주요 지표를 모아 전월 대비 증감을 정리하고 윗선에 공유한다. 이 월 단위 작업을 실시간 대시보드로 바꿔, 화면만 열면 4개 채널 지표와 증감이 바로 보이게 하려 한다.

## 등장인물

- **담당자** — 홍보팀에서 대내외 커뮤니케이션 채널을 운영하며, 매달 채널별 지표를 취합하고 증감을 정리하는 사람
- **팀장·윗선** — 담당자가 정리한 지표 보고서를 공유받는 사람
- **유튜브** — 구독자수·조회수·시청시간 통계를 제공하는 외부 채널
- **인스타그램** — 팔로워·도달수·저장수 통계를 제공하는 외부 채널
- **네이버 블로그** — 조회수·방문자수 통계를 제공하는 외부 채널
- **온라인사보** — 방문자수·조회수 통계를 제공하는 사내 채널

## 오가는 것

- **채널별 주요 지표** — 각 채널 관리자 페이지에서 확인하는 숫자
  - 유튜브: 구독자수, 조회수, 시청시간
  - 인스타그램: 팔로워, 도달수, 저장수
  - 네이버 블로그: 조회수, 방문자수
  - 온라인사보: 방문자수, 조회수
- **엑셀** — 각 채널에서 확인한 숫자를 옮겨 적는 중간 정리 파일
- **지표 보고서** — 4개 채널 지표와 전월 대비 증감이 채워진 보고서 양식
- **실시간 대시보드** — 화면을 열면 4개 채널 지표와 증감이 한눈에 보이는 화면

## 흐름

1. 담당자가 유튜브·인스타그램·네이버 블로그·온라인사보 관리자 페이지에 각각 로그인한다.
2. 담당자가 채널별 주요 지표를 눈으로 확인한다.
3. 담당자가 확인한 숫자를 엑셀에 옮겨 적는다.
4. 담당자가 엑셀에서 이번 달 숫자를 지난달과 나란히 놓고 증감을 비교한다.
5. 담당자가 4개 채널 지표와 증감을 보고서 양식에 정리한다.
6. 담당자가 지표 보고서를 팀장·윗선에 공유한다.

## 예외

- 특정 채널 숫자가 갑자기 튀거나 떨어질 때 → 담당자가 개별 콘텐츠 단위로 들어가 원인을 확인한다. (이 자동화 시스템의 범위 밖 — 스킵)

## 끝나는 지점

- 지금 방식: 4개 채널 지표와 전월 대비 증감이 보고서 양식에 다 채워져 팀장·윗선에 공유되면 그 달 일이 끝난다.
- 만들려는 대시보드: 화면을 열었을 때 4개 채널 지표와 증감이 한눈에 보이면 된 것이다.

## 지금의 불편함

- 매달 4개 채널 관리자 페이지에 일일이 로그인해서 숫자를 확인해야 한다.
- 확인한 숫자를 엑셀에 옮겨 적는 것이 제일 번거롭다.

## 용어

| 용어 | 뜻 |
|---|---|
| 온라인사보 | 사내 채널. 방문자수·조회수를 주요 지표로 봄 |
| 도달수 | 인스타그램 지표. 콘텐츠가 도달한 수 |
| 저장수 | 인스타그램 지표. 게시물이 저장된 수 |
| 시청시간 | 유튜브 지표 |
| 증감 비교 | 이번 달 숫자를 지난달과 나란히 놓고 늘었는지 줄었는지 보는 것 |
